# 通知与后台运行

1.0.6 起，登录并完成隐私模式选择后，可在「设置 → 通知与后台运行」主动开启消息通知。默认关闭；每次重新开启都恢复为隐蔽提醒。首次开启先补齐历史，不对既有积压消息发出提醒。暂停后恢复则可以提示暂停期间的新消息。

隐蔽提醒只显示番茄钟名称和休息提示，无内容、发送者、声音、振动或角标。真实信息需单独确认；手机解锁时可以显示发送者及最多 160 字文字，图片和文件仅显示类型。熄屏/锁屏时改为通用提醒。真实信息可能被系统通知历史及拥有通知访问权限的应用保存，应用无法追回这些副本；这些限制在设置中说明。

隐私模式继续保护全部应用界面。通知和磁贴不能解锁聊天，也不触发更新检查。隐蔽通知、常驻通知打开番茄钟；真实通知打开经过隐私锁的主界面。新版 Android 可能自动生成不带原始 Intent 参数的汇总通知：存在未清除的隐蔽提醒时，无明确目标的启动也先显示番茄钟，正常模式可点击「返回」。

后台服务使用 Android `specialUse` 前台服务，Manifest 声明具体用途：没有厂商推送的设备上，用户主动开启的持续消息连接。不会冒用音频、定位、无障碍、VPN 或其他服务类型。常驻通知和快捷设置磁贴都可以暂停后台提醒；重新打开应用不会自动取消用户的暂停选择。Android 13+ 支持在应用内请求添加磁贴，旧版需在快捷设置编辑区手动添加。

服务共用 Repository、加密数据库及同步游标。消息入库并提交游标后再处理提醒，过滤本人消息、已读位置、个人清理线及本地销毁线；前台已显示聊天时不重复通知。WebSocket 断开和网络恢复会唤醒同步，正常运行每 30 秒兜底检查，失败退避至 60 秒。通知仅保留最新一条，不等同于可靠消息投递：极端进程终止或网络错误可导致未提醒，但重新打开仍通过同步补齐未销毁记录。

配置使用本机加密保险库保存并绑定用户 ID。新登录、退出或会话撤销会关闭通知并清理消息通知。开机、包升级尝试恢复已开启且未暂停的服务；配置或凭据不可读时停止，不能自动恢复到可访问状态。

移除最近任务与强行停止不同。`stopWithTask=false` 保留用户已开启的服务，但强停、系统「停止」、Doze、断网和厂商电池/自启动限制仍可中断接收；必须允许通知并按需配置后台运行。磁贴只是服务开关，不是绕过系统限制的常驻机制。

依据：[Android 前台服务类型](https://developer.android.com/develop/background-work/services/fgs/service-types)、[用户停止服务](https://developer.android.com/develop/background-work/services/fgs/handle-user-stopping)、[快捷设置磁贴](https://developer.android.com/develop/ui/views/quicksettings-tiles)、[通知分组](https://developer.android.com/develop/ui/compose/notifications#notification-behaviors)。
