## 已通过

- 服务端：15 项测试分别在 SQLite、PostgreSQL 17 和 GitHub Actions 通过；Ruff 通过。生产依赖完成 pip-audit，检查时未发现已知漏洞。
- Android：Debug/Release 构建、5 项 JVM 单元测试、Lint 通过；正式构建启用 R8 和资源压缩。
- Android 16 / API 36（x86_64，独立模拟器）：冷启动隐藏、手势解锁、后台和 Activity 重建重新锁定、配置缺失保持锁定、过期计时不补响铃、Room 消息与游标事务回滚。
- 公网 `https://chat.worldofmy.uk`：管理员登录、开户、强制首次改密、好友申请、文字、PNG 和 UTF-8 文件、鉴权下载、WSS 同步提示。两个验收账号用于联调，结束后停用。
- Android 对接生产 HTTPS：历史同步、设备端发送、图片预览、UTF-8 文本预览及两页 PDF 渲染/翻页均通过。
- 100 个同时在线 WebSocket 的短时测试：50 条消息、50 次同请求重试、100 个事件流全部核对，无重复。该次测试耗时 3.24 秒；这不是长时间容量或弱网测试。
- 一致性备份恢复：将快照恢复到独立 PostgreSQL 数据库，恢复 3 个账号、3 条消息，并核对 2 个附件的完整 SHA-256。没有覆盖生产数据库。每日备份 timer 已启用，保留 7 天。
- 安装包校验：用实际 APK 验证大小、哈希、错误包名、不同签名均被拒绝；相同证书的更高版本可通过校验。
- 覆盖升级：同签名测试包 `versionCode 1 → 2`，通过系统包管理器覆盖安装后，加密凭证文件、Room 所有者/游标/消息数、隐私图案和运行中的计时状态均保留。首次启动保持番茄钟，原图案可解锁。测试包未发布；正式首版仍为 `1.0.0 / 1`。旧测试包未压缩以便植入验收状态，新测试包启用正式 R8 压缩；数据库版本均为 1。
