# 验证记录

此文档会在发布前填写实测结果。未实测的项目不视为通过。

## 已准备的检查

- 服务端：账号限制、精确搜索、好友确认、幂等、分页、未读、个人清理、附件鉴权、图片验证、同步游标、WebSocket、管理权限与 CSRF。
- Android 单元测试：图案跨中点、重复点处理、更新版本比较、恶意清单拒绝。
- Android 设备测试：冷启动隐藏、图案解锁、后台及重建加锁、损坏配置保持锁定、Room 事务回滚。
- CI 使用 SQLite 和独立 PostgreSQL 测试数据库；正式发布增加签名、清单和远程 Release 附件核验。

## 待记录

- 设备/模拟器实测与截图。

- 首次正式 Release 及匿名更新下载验证。
