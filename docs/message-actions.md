# 消息撤回与本机清理

- 长按已发送消息可选择本地删除；双方当前登录客户端均支持撤回时，本人消息可选择撤回。撤回由服务端校验发送者和能力，不限制发送时间，重复撤回成功且不重复产生事件。
- 撤回保留不含正文、附件或引用的占位记录，仅管理员在聊天历史中看到提示；普通用户的历史、上下文和会话摘要不显示占位记录，通过双方的消息同步事件更新。原附件从服务器删除，原消息引用与发送重试被拒绝。
- 新客户端发送 `X-Touch-Capabilities: recall-v1`；登录及 `/auth/me` 更新当前会话能力，`/auth/me` 的 `capabilities` 表示服务端支持的能力，会话的 `can_recall` 决定入口是否可用。一方未升级时禁用新的撤回，正常收发仍兼容。
- 旧客户端或回滚客户端同步遇到既有撤回状态时，服务端返回 HTTP 409：`此会话包含新版消息状态，请更新 Touch 后继续同步`。历史、上下文及摘要只在实际需要返回撤回记录时拒绝，不返回原正文，也不转换为普通文本或假附件。普通用户已经过滤的撤回记录不会因此阻断历史分页。
- 本地删除在当前账号的加密数据库写入消息 ID 标记，并删除本机消息与附件。账号级标记及清理线保存在独立表，退出、重新登录和切换账号时仍保留；物理附件删除失败时保留清理队列并重试。同步、历史、引用和上下文加载都遵守该标记，不调用服务端个人清理接口。
- 设置中的清空本地聊天记录删除消息、附件、草稿和待发送项，保留账号、联系人、配置及同步游标。记录本机时间清理线和当前秒消息 ID，避免恢复旧消息，同时允许当前秒产生的新消息到达。时间清理依赖手机时间正确。
- 删除和撤回会使已打开的本机附件句柄失效，并刷新引用预览和消息通知。已被对方复制、截图或保存到外部应用的内容不能追回；离线设备需联网同步后才更新。
- 撤回需要先部署包含新接口及 `a731c02e9714` 会话能力迁移的服务端；单独安装新版客户端不能提供服务端撤回能力。
