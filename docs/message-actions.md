# 消息撤回与本机清理

- 长按已发送消息可选择本地删除；本人消息可选择撤回。撤回由服务端校验发送者，不限制发送时间，重复撤回成功且不重复产生事件。
- 撤回保留不含正文、附件或引用的占位记录，仅管理员在聊天历史中看到提示；普通用户的历史、上下文和会话摘要不显示占位记录，通过双方的消息同步事件更新。原附件从服务器删除，原消息引用与发送重试被拒绝。旧客户端未升级时可能把占位记录显示为附件，应同时更新客户端。
- 本地删除仅在当前账号的加密数据库写入消息 ID 标记，并删除本机消息与附件。同步、历史、引用和上下文加载都遵守该标记，不调用服务端个人清理接口。
- 设置中的清空本地聊天记录删除消息、附件、草稿和待发送项，保留账号、联系人、配置及同步游标。记录本机时间清理线和当前秒消息 ID，避免恢复旧消息，同时允许当前秒产生的新消息到达。时间清理依赖手机时间正确。
- 删除和撤回会使已打开的本机附件句柄失效，并刷新引用预览和消息通知。已被对方复制、截图或保存到外部应用的内容不能追回；离线设备需联网同步后才更新。
- 撤回需要部署包含新接口的服务端；单独安装新版客户端不能提供服务端撤回能力。
