# 1.0.9 验证记录

## 实现

- 引用仅持久化 ID、序号和时间，不复制原文；服务端检查会话权限、个人清理位置和截止时间，定位最多返回 50 条。
- Room 1 → 2 显式迁移，保留 SQLCipher 加密数据库；增加会话/序号、种类/时间、附件索引。读取每页 50 条，引用和读取同时过滤过期内容。
- 数据库变更驱动界面刷新；历史窗口固定边界，返回最新消息由用户主动触发。发送确认前不显示成功，旧待发送项不自动重发。
- 加密草稿默认关闭，保存在 SQLCipher 内，只包含文字、引用标识及最后编辑时间；可靠写入待发送队列后清理。关闭、删除会话和退出账号均清理。
- 状态栏诊断仅包含连接状态、时间、次数、固定错误类别和后台服务状态；详细记录默认关闭，最多保留本进程 40 条脱敏事件。
- 图片预览处理 EXIF 旋转/镜像，双击切换缩放并复位；解码来自加密流，不生成明文缩略图。

## 已完成的本地验收

- Android 模拟器 API 36.1：存储和隐私测试 14 项通过，含真实 v1 数据库迁移、加密完整性及查询计划检查。
- SQLCipher 1 万/5 万条消息各读取 50 条：约 4/5 ms（本机单次测量，不代表所有手机性能）。查询计划使用会话索引，无跨会话全表扫描。
- 引用菜单、取消引用、加密草稿恢复、可靠入队清稿、定位及过期引用保留输入的端到端测试通过。
- 初次连接、WebSocket 失败、HTTP 正常但实时通道断开、前后台恢复及刷新竞态回归 4 项通过。
- 缩略图、最近任务隐藏、翻面/摇动快速退出回归 2 项通过。

## 限制

真机 Android 10/12/13、无 Google 服务的国内机型、厂商省电策略、真实 Doze 长时间休眠及多种移动网络切换尚未在本轮验证。系统强行停止后不承诺后台收信。上述测试使用隔离账号，不读取生产消息内容。

正式 CI、发布、生产迁移及覆盖升级结果在完成后补记。
