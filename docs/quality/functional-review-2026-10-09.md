# 2026-10-09 功能复查与修复

基于 2.0.6 复查客户端隐私门控、系统选择器、发送与重试、附件确认、撤回、联系人、资料、通知、导出、更新、计时，以及服务端上传与消息接口。本轮保持现有版本号和协议，不涉及生产环境发布。

## 已修复的确认缺陷

| 问题 | 修复与边界 |
| --- | --- |
| 隐私模式打开照片、文件或头像选择器，被普通后台处理锁回番茄钟 | 保留暂停时立即遮罩和锁定；仅允许与原账号、会话、页面及导航代次一致的单次选择器结果恢复。取消也返回原页。Home、最近任务、锁屏、新 Intent、重建会使恢复授权失效。授权和 URI 不进入明文保存状态。 |
| 选择结果可能带入其他会话；暂停期间重绘可能移除遮罩 | 会话切换、离开对应页面清除旧选择；Activity 未恢复时不移除安全遮罩。 |
| 待发队列入库及发送完成时短暂显示失败，超时后又变成功 | 入队前登记发送中；加密待发记录区分待发送、等待确认和明确失败。丢失响应、网络中断及暂时服务故障显示等待确认；后续同步可确认已发送。手动重试继续使用原 client_id。 |
| 发送、撤回、资料或联系人已成功，后续同步失败却报操作失败 | 服务器确认与后台同步分开。撤回立即抹除本机原文、引用和附件；联系人接受/拒绝/删除立即更新本机关系；未同步到会话 ID 前不提供无效聊天按钮。 |
| 刷新令牌成功后凭据落盘失败，可能被当作网络等待 | 凭据持久化使用独立异常；保留旧内存凭据，明确显示存储错误，不吞掉取消和本地数据异常。 |
| 上传中按返回或点遮罩关闭确认框，上传却继续 | 上传期间阻止返回键、遮罩误关和重复提交；保留明确的“取消上传”，仅停止当前附件或头像上传并清除选择与进度，不影响其他请求。聊天中的在途待发项也不能被删除。 |
| 撤回、清理或锁屏与通知生成交错，旧正文可能再次被发布 | 通知读取绑定代次，发布与清除共用锁；发布前再次检查账号、模式、权限与锁屏。过期清理和服务端清历史同时收回失效通知。 |

## 验证记录

- 服务端 SQLite：122 项通过，1 项 PostgreSQL 专项跳过；Ruff 通过。
- Android：调试应用和设备测试包编译通过；37 项单元测试通过；Lint 0 错误、33 条警告。
- API 36.1 核心设备回归：67 项全部通过，无失败、无跳过，包含 22 项新增设备回归。实际系统相册选图、返回原隐私会话、确认发送以及重复同步后仅一条图片消息均通过；真实 Home、熄屏、返回和重建路径通过。
- 弱网回归覆盖服务器已接收但响应丢失、503、明确 403、刷新令牌后磁盘写入失败、相同 client_id 重试，以及确认成功后的独立同步失败。上传取消回归覆盖附件和头像，验证并行请求仍能完成、选择和进度已清除、取消结果不写资料或发送消息。通知发布和清除的并发边界另有 2 项单元回归。
- 测试使用隔离 API 36.1 模拟器、回环地址服务、虚构账号和独立数据库，不访问真实聊天数据。
- 新增消息确认、资料操作和联系人变更测试已纳入 CI / Release 共用设备门槛；隐私和交互回归加入现有测试类。

## 兼容与未实测范围

待发状态保存在现有加密 JSON 中，无 Room schema 变化；旧待发记录按等待确认处理。内部状态字段不会发送到服务器。继续使用现有消息幂等标识和撤回协议。

本轮未重新实测国内品牌真机、其他 API 模拟器、PostgreSQL、历史正式签名覆盖升级或发布构建性能，不将其计为通过。当前改动未发布到 GitHub Release 或生产服务。

本机证据保存在 `.local/functional-review-20261009/`；只采用当前源码对应且完整结束的验证记录，已中断或使用旧测试包的运行不计入验收。

最终完整设备记录为 `device-clean-final.txt`（67 项，204.672 秒），构建记录为 `build-clean-final.log`。两项取消上传专项复测记录为 `device-cancel-focused.txt`。

复测过程中修正了原草稿测试缺少登录准备、锁屏测试未等待系统界面返回的问题，原有断言保留。复用服务的多轮登录触发过真实限流，最终使用全新的隔离服务重跑通过，未降低服务端限制。最后补充取消上传后，增量打包曾保留旧类定义；最终清理生成目录、禁用构建缓存和 Kotlin 增量编译，完整构建并重新安装，专项及完整回归均通过。旧安装包对应的失败运行不计入最终验收。
