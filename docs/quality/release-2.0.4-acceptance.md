# 2.0.4 修复更新验收

沿用 2026-10-06 使用者明确确认的正式发布决定与 2.0.3 人工验收例外。此次针对正式版反馈修复撤回菜单缺失与长按菜单改变消息高度，不伪造仍缺少的真机专项、历史正式签名包覆盖升级及性能验收记录。

生产只读核查确认：移动会话受按账号唯一约束保护，不存在重复会话；部分会话尚未登记撤回支持。旧版行为会完全隐藏撤回菜单，且对方登记支持时未通知会话更新，当前客户端可能等待五分钟兜底同步才恢复入口。

修复后，自己已发送且可见的普通消息显示撤回菜单；对方尚未支持时禁用并说明更新及打开 Touch 的要求。服务端继续拒绝不兼容撤回，能力变更通知会话双方，重复同步不会产生重复通知。菜单锚点移到气泡内部间距布局之外，展开与关闭保持气泡及下方状态行尺寸和位置不变。

发布前须实际通过新增服务端与设备回归、现有 CI、正式签名及文件完整性核验；发布后核查生产构建、公开下载和 Latest 更新文件。

本机 API 36.1 模拟器已实际运行 `ChatLayoutInstrumentedTest`：10 项全部通过，包含 6 项此次新增的长按菜单与撤回状态回归，以及此前的标题、发送键、会话时间、滚动和键盘行为检查。属于模拟器验证，不作为国内实体机专项验收记录。
