# 2.0.6 全局旋转偏好修复

2026-10-07，使用者要求旋转锁定覆盖所有页面，仅图片预览可按独立选项允许旋转，并明确要求“发布新版release”。本次作为正式修复版发布，沿用此前已确认的正式发布决定，继续如实保留国内真机专项、真实历史正式签名包覆盖升级及发布构建性能验收记录未齐全的状态。

开启“锁定竖屏”后，番茄钟、登录、消息列表、聊天、设置及各子页均请求竖屏。仅实际可显示的图片预览，在独立选项开启时跟随系统方向偏好；文档、隐藏后的番茄钟和隐私门禁状态均不使用图片例外。关闭全局锁定后恢复系统默认方向策略。保留原有本机偏好键，默认值及已有选择不变。

方向策略在 Compose 组合阶段读取依赖状态，确保开关变化、预览变化及隐藏立即触发应用方向，不依赖下一次导航。继续使用现有方向配置变更处理，不向 Android 保存状态写入敏感内容或解锁状态。部分大屏设备对应用方向请求的系统限制保持不变。

本地实际验证：调试应用及测试包构建成功，方向规则 3 项单元测试通过；API 36.1 隔离模拟器的 8 项隐私与方向设备回归全部通过；Lint 0 错误、33 条警告。设备回归覆盖全部导航页面、已锁定与登录页面、重建保留偏好、图片例外即时开关、返回恢复、文档不例外、关闭全局锁定及隐私隐藏。测试前后恢复旋转偏好，测试网络仅使用临时本地账号和附件。模拟器启动时的 System UI ANR 弹窗选择 Wait 后恢复正常，未修改产品或断言来绕过环境问题。

发布前继续执行完整多 API 设备门槛、服务端 SQLite/PostgreSQL 检查、正式签名构建、独立下载校验和公开 Latest 入口验证。服务端业务及数据库迁移不变，部署只同步本次构建版本与标识；现有服务端单方撤回回归保留。各项结果以实际发布记录为准，不将上述未实测项目作为通过项。
