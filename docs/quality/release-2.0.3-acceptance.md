# 2.0.3 正式发布决定

2026-10-06，使用者报告试用其他功能正常，要求修复撤回后发布正式版。在说明缺少真机通知、后台返回、Doze、断网恢复、历史签名包覆盖升级详细记录后，使用者再次明确要求按其试用确认直接发布正式版。

本次将按该明确决定发布 Latest，作为一次有记录的人工发布例外，不伪造 `release_evidence.py` 所需的专项通过结果或证据链接，不修改默认验收检查，不将试用确认等同于全部专项实测。CI、设备自动化、签名、版本、哈希及公开下载校验仍须实际通过。

撤回缺失根因：生产 `/opt/touch` 仍部署 `9c837b4`，健康接口报告 `1.0.0`，实际路由没有撤回接口；新版客户端没有收到 `can_recall`，按兼容规则隐藏入口。修复包含生产服务端备份、迁移和配套代码升级，以及旧会话不重新登录恢复能力的回归。

待补充专项记录：国内实体机型号与系统版本、通知/后台/Doze/断网恢复记录、历史正式签名包覆盖升级记录、发布构建性能数据。这些项目保持未验证，不宣称通过。
